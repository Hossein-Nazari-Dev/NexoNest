Step Evenly

Equal parameter intervals.

#

Distribute parameters uniformly across the curve domain. Equal parameter steps do not generally create equal-length segments.

Inputs
Curve C; segment count n ≥ 3; Include Kinks; Custom Points; Min Length.
Outputs
Sorted parameters, evaluated points and a polyline.

Formula / logic

tᵢ = t₀ + i(t₁ − t₀)/n,  i = 0…n
Pᵢ = C(tᵢ)

Custom points and optional C1 breaks enter the shared priority merge, so the final segment count can differ from n.

Space Evenly

Equal arc-length intervals.

#

Divide the source by equal arc length using Rhino DivideByCount, then apply the shared segmentation pipeline.

Inputs
Curve C; segment count n ≥ 3; Include Kinks; Custom Points; Min Length.
Outputs
Parameters, points and a polyline.

Formula / logic

s(tᵢ) = iL/n
s(t) = ∫[t₀,t] ‖C′(u)‖ du;  L = s(t₁)

Custom points, kinks and minimum-length merging can modify the final equal-spacing pattern.

Follow Bends

Adaptive segmentation by curvature.

#

Sample the parameter domain and retain samples whose curvature magnitude reaches the threshold. This is a threshold screen, not recursive error control.

Inputs
Curve; curvature threshold κmin ≥ 0; Sample Count N ≥ 3; shared segmentation controls.
Outputs
Retained parameters, points and polyline.

Formula / logic

tᵢ = t₀ + i(t₁ − t₀)/N
keep tᵢ when ‖CurvatureAt(tᵢ)‖ ≥ κmin

Domain ends are included. Curvature has inverse-length units; a dense enough sample grid is needed to detect short bends.

Follow Turns

Adaptive segmentation by tangent direction.

#

Compare each sampled unit tangent with the tangent at the last accepted sample. Accept and update the reference when the angle reaches the threshold.

Inputs
Curve; angle threshold; Sample Count N ≥ 3; shared segmentation controls.
Outputs
Parameters, points and polyline.

Formula / logic

θ = acos(clamp(Tref · T(t), −1, 1))
keep t when θ ≥ θmin; then Tref ← T(t)

T denotes a unit tangent. The angle input supports Grasshopper degree/radian settings; internal comparisons use radians. Sampling can miss changes between candidates.

Follow Shape

Adaptive segmentation by chord error.

#

Recursively compare sampled curve points with the finite chord of the current interval. Split at the sample with greatest deviation.

Inputs
Curve; error tolerance ε > 0; Sample Count ≥ 3 per interval; Min Length; shared segmentation controls.
Outputs
Subdivision parameters, points and polyline.

Formula / logic

e(a,b) = maxⱼ d(C(a + j(b−a)/N), [C(a), C(b)])
if e > ε: split at the largest-error sample

d is distance to a finite line segment. Recursion also stops at the minimum-length/parameter guard. The sampled test is not a proven continuous maximum bound.

Clean Angles

Simplify by angular change.

#

Keep vertices where the angle between neighboring edge directions reaches the threshold. Short adjacent edges are protected.

Inputs
Polyline with at least 3 distinct vertices; positive angle threshold; nonnegative minimum segment length.
Outputs
Simplified polyline, removed-vertex count and reduction percentage.

Formula / logic

θᵢ = angle(Pᵢ − Pᵢ₋₁, Pᵢ₊₁ − Pᵢ)
keep Pᵢ if θᵢ ≥ θmin
Reduction (%) = 100(Nold − Nnew)/Nold

Tests use original neighboring vertices. End vertices and at least one interior vertex remain; closed output is reclosed. This is not a global chord-error guarantee.

Clean Shape

Simplify with a chord-based method.

#

Test each interior vertex against the finite chord joining its original neighbors; keep it when the local distance exceeds tolerance.

Inputs
Polyline; distance tolerance ε ≥ 0; minimum segment length ≥ 0.
Outputs
Simplified polyline, removed count and reduction percentage.

Formula / logic

eᵢ = d(Pᵢ, [Pᵢ₋₁, Pᵢ₊₁])
keep Pᵢ if eᵢ > ε
Reduction (%) = 100(Nold − Nnew)/Nold

Vertices beside protected short edges are retained. Local decisions do not guarantee the final polyline stays within ε of every removed vertex.

Clean Overall

Douglas-Peucker simplification.

#

Apply Douglas-Peucker subdivision: find the original interior vertex farthest from an interval chord, retain it if over tolerance and recurse on both sides.

Inputs
Polyline with at least 3 distinct vertices; distance tolerance ε ≥ 0.
Outputs
Simplified polyline, removed count and reduction percentage.

Formula / logic

j* = argmax[a<j<b] d(Pⱼ, [Pₐ, Pᵦ])
if d(Pⱼ*, [Pₐ, Pᵦ]) > ε: retain j* and recurse

The implementation retains end vertices and at least one interior vertex, and restores closure. Tolerance is tested on the input polyline vertices, not against a separate smooth source curve.

Find Crossings

Inspect curve self-intersections.

#

Use Rhino self-intersection events to identify point crossings and overlap endpoints.

Inputs
A valid curve; the active Rhino model tolerance.
Outputs
Intersection points, event parameters and a HasIntersection boolean.

Formula / logic

events = CurveSelf(C, tolerance)
HasIntersection = (reported point count > 0)

Overlap events contribute their endpoints. Detection depends on model tolerance; the segmentation pipeline rejects self-intersecting input.

Check Shape

Measure maximum and relative chord error against the source curve.

#

Split the source curve at polyline vertices, sample each matched span by arc length and measure distance to its corresponding finite chord.

Inputs
Original curve; ordered approximation polyline; Samples per Segment.
Outputs
Maximum error, relative error, local errors, source subcurves and error-point pairs.

Formula / logic

eᵢ = max[t in sampled span i] d(C(t), [Pᵢ, Pᵢ₊₁])
MCE = maxᵢ eᵢ
rMCE = MCE / Lsource

Polyline vertices must lie on the source within the active model tolerance and follow its order. MCE has model-length units; rMCE is a dimensionless ratio, not a percentage. Sampling is not an exact continuous supremum.

Find Kinks

Locate continuity breaks and critical points.

#

Find parameters where the selected Rhino continuity condition fails. The selector determines which kind of discontinuity is searched.

Inputs
Curve; Type code; Include Ends; positive Step Tolerance.
Outputs
Critical parameters and evaluated curve points.

Formula / logic

Find t where the chosen continuity condition fails
P = C(t)

C1 is the usual kink-preservation choice. C1 compares first derivatives; G1 compares tangent direction. Locus variants change endpoint treatment through Rhino continuity rules.

Match Length

Scale a curve to a target arc length.

#

Scale uniformly about the curve start point. An optional Plane first aligns a planar curve normal with the target plane normal.

Inputs
Curve; Target Length; optional Plane.
Outputs
Scaled curve and scale factor.

Formula / logic

k = Ltarget / Lcurrent
P′ = A + k(P − A),  A = curve start

Current and target lengths must exceed the model tolerance. Optional rotation precedes scaling; the anchor remains the start point.

t to Points

Evaluate curve points at parameters.

#

Evaluate accepted parameters on the source curve. Tolerance widens the accepted domain interval; the current implementation does not clamp accepted values to its ends.

Inputs
Curve; parameter list; nonnegative domain tolerance δ.
Outputs
Evaluated points and rejected OffDomain parameters.

Formula / logic

accept t when t₀ − δ ≤ t ≤ t₁ + δ
P = C(t)

This tolerance is in parameter units, not model distance. Values outside the accepted range are reported, not silently replaced.

Points to t

Project points to curve parameters.

#

Project each point to its closest location on the curve and accept it only if its distance is within tolerance.

Inputs
Curve; point list; nonnegative distance tolerance τ.
Outputs
Accepted curve parameters and rejected OffCurve points.

Formula / logic

t* = closest curve parameter to P
accept when ‖P − C(t*)‖ ≤ τ

OffCurve points are reported separately. Distance tolerance uses model-length units; projection does not preserve the original point order along the curve.

Write JSON

Record polyline geometry as JSON.

#

Keep unique input polylines in the component session and write the full collection beside the saved Grasshopper document.

Inputs
Polyline; file name; Reset switch.
Outputs
Identifiers, vertex tree, JSON dictionary and output path.

Formula / logic

same(A,B) ⇔ same vertex count and
‖Aᵢ − Bᵢ‖ ≤ model tolerance for every ordered pair

This is data serialization, not a geometry formula. A saved Grasshopper document provides the output folder. Same-order matching matters; Reset clears memory and the JSON file.

Read JSON

Read polyline geometry from JSON.

#

Read the recorded polyline dictionary, select an entry by index and reconstruct a polyline from its stored ordered vertices.

Inputs
JSON file path; entry index.
Outputs
Polyline, points, identifier and total entry count.

Formula / logic

JSON entry → ordered vertices [P₀,…,Pₙ] → Polyline

No geometric formula is applied. A valid compatible file and an in-range index are required; reading JSON does not regenerate the original NURBS curve.

Sort Points

Merge and sort points along a curve.

#

Project up to three priority point sets onto the curve. Sort by parameter and merge nearby candidates using distance along the curve.

Inputs
Curve; Priority 1/2/3 point lists; Point Tolerance; Merge Tolerance.
Outputs
Merged sorted parameters and corresponding curve points.

Formula / logic

dcurve(a,b) = length(C restricted to [min(a,b),max(a,b)])
merge when dcurve ≤ Merge Tolerance
Priority 1 > Priority 2 > Priority 3

Off-curve points are ignored with a warning. Higher priority wins a merge; equal priority retains the previously accepted candidate. Merge distance is arc length, not raw parameter difference.

Split at Points

Split a curve at projected points.

#

Project valid split points, clean and sort their parameters, then trim successive source intervals.

Inputs
Curve; split points; Point Tolerance.
Outputs
Curve segments and their arc lengths.

Formula / logic

tᵢ = accepted, sorted split parameters
segmentᵢ = C restricted to [tᵢ, tᵢ₊₁]

Off-curve points are reported. Duplicate/seam parameters are cleaned and closed curves require wrap-around handling. No valid split candidates can produce no segments.

Continuity selector

Select the continuity type used by detection tools.

#

Pick the Rhino continuity condition sent to Find Kinks. This is a value-list control, not a curve solver.

Inputs
Select a continuity option from the dropdown.
Outputs
Integer Type code for Find Kinks.

Formula / logic

C0: matching position
C1: matching first derivative; C2: also second derivative
G1: matching tangent direction; G2: curvature continuity

Pick Continuity defaults to C1. Codes 0…9 cover C0/C1/C2/G1/G2 and their locus variants; Rhino evaluates these with its continuity rules.
