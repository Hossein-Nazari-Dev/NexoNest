Overview

“Harmonizing Spaces, Humanizing Experiences”

TectoTrack is a social digital twin that mirrors real environments in a live, data-driven model. It observes how people move, gather, and interact, then translates those behaviors into spatial insight you can design with.

By coupling agent-based modeling with live and historical data streams, the platform helps architects, planners, and researchers forecast pedestrian flow, evaluate comfort, and test scenarios before they’re built.

Key Features

Real-Time Simulation

Ingests live inputs and supports real-time or time-lapse playback; integrates IoT and environmental feeds.

Agent Profiles

Configurable behaviors for wayfinding, clustering, inclusivity and safety; libraries for different user types.

Spatial Analytics

Flow and density metrics, interaction hotspots, heatmaps, conflict detection, bottleneck analysis.

Scenario Testing

What-if design evaluation, evacuation drills, capacity planning, utilization forecasting.

Applications

Signage & Wayfinding

Analyze simulated flows to position signs where they resolve confusion and shorten paths.

Advertising Placement

Use persona-driven data and heatmaps to target content at high-attention nodes.

Airport Revenue

Optimize dwell time, retail exposure, and service mix; detect maintenance cycles from usage patterns.

Retail & Shopping Malls

Evaluate layouts before construction and tune existing spaces to improve flow and conversions.

My Contributions

Data Pipeline

  • Extracted geometry and metadata from Revit/BIM and normalized for simulation.
  • Automated model conversion and versioning for Unity ingestion.
  • Established update triggers so design changes propagate reliably to the twin.

Result: consistent, repeatable handoff from design to analysis with minimal manual prep.

Simulation & Analytics

  • Processed outputs into flow, density, and interaction metrics.
  • Built comparison reports and dashboards from sensor and sim datasets.
  • Validated models via trend analysis and sanity checks against observed patterns.

Result: simulations translate into decision-ready evidence instead of raw data dumps.

Perception & Wayfinding

  • Implemented gaze/field-of-view logic and isovist-based visibility.
  • Prototyped cognitive wayfinding for more human-like route choice.
  • Tuned agent reactions to local congestion and points of interest.

Result: agents respond credibly to space, improving the realism of crowd dynamics.

Computational Geometry

  • Built visibility graphs and spatial indices for fast queries.
  • Optimized vector/matrix operations for movement and rotation.
  • Hardened geometric routines to keep frame times stable.

Result: performant core routines that scale with scene size and agent count.

Academia & Outreach

In 2024, Morphotect partnered with the Iran University of Science and Technology (IUST) to host a hands-on bootcamp on agent-based modeling and social digital twins. The program guided students through practical coding workflows — translating spatial problems into simulation logic and iterating toward evidence-based design feedback.

Bootcamp Outcomes

  • Students learned to extract geometry, build agent profiles, and run crowd simulations.
  • Cross-disciplinary teams tackled real urban and architectural problems, developing prototype solutions.
  • Introduced a repeatable workflow: data → model → metrics → design feedback.
