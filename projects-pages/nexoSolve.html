Question

How can you explore a finite design space without losing progress, results, or the calculation context?

Work in the NexoSolve Windows app. Its Grasshopper plugin connects the app to your definition: inputs go in, calculated results come back, and the app saves each case locally.

Choose the values you actually need

Name your variables, add units and descriptions, and preserve the order of custom values. Use connected sliders or explicit numeric lists to define the finite domain.

06

Review before you run

Check the full case count, project destination, timing and completion settings before starting. Exhaustive enumeration grows with the product of the variable value counts; choose a manageable domain.

07

Pause safely. Continue later.

Pause or stop after the current case is saved. Resume a saved study with its recorded progress and execution settings. Synchronous Grasshopper components may need to return before a pause or timeout can take effect.

08

Reuse compatible results

Expand or change a study domain without recalculating matching successful cases when the underlying calculation remains compatible.

Saved model copies and calculation signatures help keep the study context available for comparison and recovery.

Changes to the calculation can block reuse. External data and solver changes require an explicit revision so earlier results are not silently treated as equivalent.

Calculation ownership

NexoSolve manages the sequence and persistence. Validate the analysis and registered outputs on your own Grasshopper definition.

09

Keep results on your computer

Each committed case is saved locally. Reopen the study to review progress and continue when needed. Export numeric results as CSV, with per-scenario result and geometry files and optional viewport images. Model backups support recovery and comparison. The licensing service handles account and activation information; it does not receive your models or study results.

Install the complete package

  1. 01

    Install the Grasshopper connector

    Get the NexoSolve plugin through food4Rhino or Rhino Package Manager. Restart Rhino after installing or updating the plugin.

  2. 02

    Download the Windows app

    Use Download NexoSolve for Windows on this page to download the app ZIP directly. Or add NexoSolve > Help > NexoSolve Club and click Download / Update NexoSolve for a verified app installation.

  3. 03

    Keep the installation together

    For manual setup, extract the app ZIP into %APPDATA%/Grasshopper/Libraries/NexoSolve-Portable-Windows-x64 alongside NexoSolve.gha. Keep the EXE and official Samples together. Close NexoSolve before replacing app files.

  4. 04

    Connect and work in NexoSolve

    Keep Rhino and your Grasshopper definition open. On Nexo Connector, click Open NexoSolve. The Windows app is a separate workspace; the connector transfers case inputs and calculated results. If needed, set App Path to the extracted executable.

16

Questions

Where do I work?

Configure, run and review studies in the standalone NexoSolve Windows app. The plugin inside Grasshopper connects that workspace to your definition. Rhino and Grasshopper perform the model calculations and must remain open.

Is it an optimization solver?

The current desktop runs exhaustive finite studies. It does not automatically search for an optimum or offer optimizer selection.

Can I use my own simulation components?

Your Grasshopper definition owns the analysis. Register its inputs and numeric outputs, then validate the study on your own definition.

Does it update automatically?

App updates are user-started: use Download / Update NexoSolve in NexoSolve Club. Grasshopper plugin installation and updates are managed separately through Rhino Package Manager.

Can I move to another computer?

Contact support for a device transfer. Trial history and license expiry remain unchanged.
