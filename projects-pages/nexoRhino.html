Question

How can writing Rhino Python become easier to explore and learn outside Rhino's own editor?

Response

NexoRhino describes RhinoCommon with .pyi files, giving editor analysis tools the types, signatures, and explanations they need without executing Rhino.

219 bundled Python stub files
205 public Rhino.Geometry types in the baseline
2 editors VS Code and PyCharm integrations
No pip needed for bundled editor plugins
01

What NexoRhino provides

Code completion

Discover geometry types and members while writing Rhino Python scripts.

Signatures and types

Inspect parameter names, return types, and available declarations before running your script.

Learning in context

Read educational docstrings, geometry notes, and examples alongside your code.

One shared baseline

The editor plugins bundle the same RhinoCommon stub collection as the Python distribution.

02

Geometry learning reference

Read 182 authored geometry lessons alongside the API signatures: parameters and arc length, local frames, tolerance, NURBS, surface trimming, mesh topology, spatial indexing, and transformations. Every one of the 205 Geometry classes has a class tag and permanent link; represented members have their own exact targets. Topic filters and search help locate a concept. Ctrl+Q in PyCharm shows an exact clickable #Class.Member learning tag. The extended reference includes 25 concept tutorials, 14 worked numerical explanations with common mistakes and related lessons, and 16 in-memory Rhino Python examples.

03

VS Code installation

  1. 01

    Install

    Search for NexoRhino by NexoNest in Extensions, or install a supplied VSIX using Install from VSIX.

  2. 02

    Enable editor support

    Use VS Code 1.85 or newer with the Python and Pylance extensions. Open a project folder you trust and wait for Pylance to finish loading.

  3. 03

    Automatic setup

    Pylance is configured automatically for each workspace folder. Use NexoRhino: Repair IntelliSense Configuration only if you need to repair or re-enable setup.

  4. 04

    Explore

    Write import Rhino.Geometry as rg, then use Ctrl+Space for completion and Ctrl+Shift+Space inside a call for parameters. Hover over a class or method, or run Show or Focus Hover (Ctrl+K, then Ctrl+I). Click its Learn more URL to open the exact live lesson. Choose Open if VS Code asks to open that website; no Trusted Domains change is needed.

04

PyCharm installation

  1. 01

    Check compatibility

    PyCharm plugin 1.1.1 supports PyCharm 2023.3 through 2026.2.x (builds 233–262), including Community and Professional/unified editions. It is submitted to JetBrains Stable and awaiting approval. The currently approved 1.1.0 supports 2026.2.x only; check Marketplace for the available update.

  2. 02

    Install

    In Settings > Plugins > Marketplace, search for NexoRhino by NexoNest and install it. Alternatively, use Install Plugin from Disk to install a supplied plugin ZIP without extracting it.

  3. 03

    Automatic setup

    Restart after installation and open a Python project. Stubs are connected automatically and restored after project synchronization. Tools > NexoRhino > Repair Code Insight Configuration is available for manual repair.

  4. 04

    Wait for indexing

    Select an existing Python interpreter so standard types resolve, then use Ctrl+Space for completion, Ctrl+Q for short geometry explanations and exact lesson links, and Ctrl+P for parameter information. The blue #Class.Member tag opens the expanded lesson for that exact symbol. The plugin adds its bundled stubs as a project library.

05

Stubs, not a runtime

A .pyi file describes an API; it does not implement or execute it. Installing NexoRhino does not install Rhino or make Rhino scripts executable in a standalone Python environment.

The bundled plugins do not need pip to deliver their stubs. Basic import resolution and geometry completion can work without an interpreter. Select an existing Python interpreter to resolve standard types and return annotations in Quick Documentation. Executing scripts still requires an appropriate runtime, and Rhino scripts require a compatible Rhino environment.

Current scope

Rhino 8's Rhino.Geometry namespace is the main focus. Supporting namespaces and .NET interop signatures remain incomplete; stable editor packaging does not imply complete API coverage.
